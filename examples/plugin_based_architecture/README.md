# Historical runtime-contract examples

These examples preserve the 0.4 embedded-validation design for migration context.
They use exact historical deployment constraints and validate objects during an
import that has already started. They are not the 0.5 static-admission quickstart
and cannot prevent earlier module side effects.

Use the [tested admission examples](../admission/README.md) for new integrations.
See the [migration guide](../../docs/migration-0.5.md) when adapting an existing
embedded `Spy.importspy` integration.
